About Aarogya Sahayak

Aarogya Sahayak is an AI-powered rural diagnostic assistant designed to provide affordable, accessible, and quick medical guidance for underserved communities. It bridges the gap between rural populations and essential diagnostic resources.

✨ Key Features

  • AI-powered hybrid diagnosis (Machine Learning + Rule Engine)
  • Free-text symptom analysis
  • Severity score with emergency alerts
  • Precautions and basic medical guidance
  • Nearest health center locator
  • Affordable diagnostic test pricing
  • Offline-ready browser system–no backend required
  • History tracking for previous diagnoses

🛠️ Tech Stack

  • HTML, CSS, Bootstrap for UI
  • JavaScript ES Modules for logic
  • Machine Learning Decision Tree (optimized JSON model)
  • Rule-Based Medical Engine
  • JSON datasets (Symptoms, Diseases, Precautions, Severity)
